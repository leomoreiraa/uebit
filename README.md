## 🐸 O que é o Uebit?

O **Uebit** é uma plataforma educacional aberta inspirada em ferramentas como **Scratch** e **Micro:bit MakeCode**, desenvolvida especialmente para crianças, jovens e iniciantes aprenderem desenvolvimento web de verdade.

Em vez de decorar regras sintáticas abstratas ou ficar preso em construtores fechados, no Uebit quem cria tem total autonomia:

- 🧱 **Monta visualmente** arrastando elementos na tela.
- 🧩 **Dá vida à página** conectando blocos lógicos de programação.
- 🔍 **Espia o código real** a qualquer momento (HTML5, CSS3 e JavaScript legítimos).
- 📦 **Leva o site para casa** em um arquivo pronto para publicar na internet.

> [!TIP]
> **Zero barreiras, zero dependências:** O site exportado pelo Uebit é puro. Ele não depende de React nem de servidores especiais — funciona com dois cliques em qualquer navegador!

## 🚀 O que dá para fazer no Uebit?

### 🎨 1. Criar Páginas com Drag & Drop
Arraste títulos, parágrafos, imagens, botões e caixas organizadoras (containers flexíveis). Ajuste cores, fontes e tamanhos em uma interface colorida e amigável feita com botões grandes e fáceis de usar.

### ⚡ 2. Programar Ações com Blocos
Use o poder do **Google Blockly** para criar interatividade:
- Fazer um botão mudar o texto da página quando clicado.
- Trocar cores de fundo ao passar o mouse.
- Criar contadores de cliques, joguinhos e histórias interativas.
- Exibir mensagens e tocar alertas com lógica de repetições e condições.

### 💻 3. Ver e Aprender o Código Real
Com um toque, abra o editor profissional integrado. O Uebit traduz cada bloco visual para **HTML semântico**, **CSS moderno** e **JavaScript nativo**. Você pode digitar código diretamente e ver as mudanças refletidas na hora!

### 📱 4. Pensar em Telas de Celular e Computador
Alterne entre as versões **Desktop** e **Mobile** com um clique para ver como a sua criação se adapta a diferentes tamanhos de tela.

### 🎭 5. Modo Palco (Play)
Oculte todas as ferramentas de edição e veja seu site em tela cheia, exatamente como os seus amigos e visitantes vão experimentar.

### 📦 6. Exportar e Publicar
Baixe seu projeto com um clique em um arquivo `.zip` contendo:
- `index.html`
- `style.css`
- `script.js`

Pronto para postar no GitHub Pages, Vercel, Netlify ou enviar para os colegas.
